🎓 School Management System — PHP CRUD Application

A hands-on bootcamp project built to demonstrate the fundamentals of web development with PHP and MySQL.
This system enables parents and administrators to manage student (ward) records efficiently using standard CRUD operations — Create, Read, Update, and Delete.
It provides a practical introduction to backend development, database integration, and user authentication — all within a clean and responsive front-end interface.

🧩 Overview

This project was developed as part of a web development bootcamp, focusing on building dynamic and data-driven applications using pure PHP, MySQL, HTML, CSS, and JavaScript.
The goal of this exercise is to help students understand how core backend processes work — from data input and validation to database interaction and display.
It also serves as a foundation for learning about session management, user roles, and basic UI/UX implementation.

⚙️ Core Features

👨‍👩‍👧 Parent & Ward Management

Parents can register, edit, delete, and view their wards’ profiles. Each record is linked to a parent account for proper data association.

🧾 CRUD Operations

Implements complete Create, Read, Update, Delete functionality using PHP and MySQL, showing real-time updates in the user dashboard.

🔐 Authentication System

Includes secure login and registration with session-based access control to protect user data.

🖼️ Media & UI Enhancements

Supports image uploads for student profiles, improving visual engagement and record identification.

📊 Dashboard View

Displays all registered wards in a structured and responsive dashboard for easy management.

📱 Responsive Design

Built with HTML, CSS, vanilla JavaScript & Bootstrap for clean, mobile-friendly layouts that work across devices.

🎯 Learning Objectives

This project teaches students to:

Understand and implement CRUD logic in PHP.

Connect and interact with MySQL databases.

Handle form submissions and server-side validation.

Manage sessions and user authentication.

Structure PHP projects with reusable scripts and logical flow.

Develop a responsive interface using core front-end tools.

🧠 Tech Stack

Frontend: HTML, CSS, JavaScript

Backend: PHP (Procedural)

Database: MySQL

Tools: XAMPP, phpMyAdmin

🚀 Getting Started

Clone or download the project folder.

Move it into your local web server directory (e.g., htdocs for XAMPP).

Import the provided SQL file (if any) into phpMyAdmin.

Start your local server and open the project in your browser:

http://localhost/school-management-system


Create a test parent account and start managing wards.
